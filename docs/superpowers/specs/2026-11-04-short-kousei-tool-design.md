# ショート構成分析ツール 仕様書

作成日: 2026-11-04

## 目的
伸びた他所のショートの「型」を記録・研究し、それを企画に流用し、投稿後の数字で「どの型が効いたか」がわかるようにする。研究・企画・振り返りを1つのツールで回す。

## 前提・制約
- MY TOOL に登録する **HTML1枚**（`short-kousei.html`）。ダブルクリックで開く。外部ライブラリ・ネット接続なしで動く（動画の再生だけはネットが必要）。
- 想定環境: Windows + Chrome / Edge（PC）。
- データはブラウザ内（IndexedDB）に保存。スクショ画像も含むため localStorage は使わない。
- バックアップ: 全データ（画像込み）を JSON で書き出し／読み込み。

## データ
### ショート（1本ごと）
- 種別: 研究（他所）／企画／自分の投稿
- タイトル、URL、チャンネル名、尺（秒）、投稿日
- 数字: 再生数、高評価数、コメント数
- 元にした型（型ID、任意）
- タグ（複数）
- 構成ブロック: [{種類, 開始秒, 終了秒, メモ}]
  - 初期の種類: フック／前振り／展開／オチ／CTA。種類は追加・名前変更・色変更できる。
- カット: [{秒, メモ}] → **カット数**と「1カットあたり平均秒数」を自動表示
- テロップメモ: [{秒, 内容, フォント, サイズ, 色, 位置, メモ}]
- SEメモ: [{秒, 種類（例: ドン、シュッ）, メモ}]
- スクショ: [{画像, 秒, メモ複数（[{ラベル, 本文}]）}]
- 自由メモ: 複数（[{見出し, 本文}]）

### 型
- 名前、元にしたショート、構成ブロック（秒数は尺に対する割合でも保持）、カット・テロップ・SEの傾向メモ

## 画面（タブ4つ）
1. **一覧**: カード表示。種別で絞り込み、タグ・キーワード検索、並べ替え（再生数／投稿日／登録日）。カードに構成の帯グラフ、カット数、スクショのサムネ1枚。
2. **編集**（1本の詳細）
   - 基本情報と数字の入力
   - **URL貼り付け → 動画を小窓（別ウィンドウ）で再生**。YouTubeショート・TikTok・Instagramリール等、URLをそのまま開く。
   - **ワンタップスクショ**: 初回だけ「画面共有」で小窓を選ぶ。以降は「📸」ボタン1回で今のコマを保存。秒数は自動で読めない（他サイトのため）ので、直前に入れた秒数を初期値にして手で直せるようにする。
   - スクショ一覧: 画像ごとに秒数とメモ欄を複数追加できる（ラベル例: 構図／テロップ／表情／その他）。画像クリックで拡大。
   - 構成ブロック: ブロックボタンを押して秒数を入れて追加。帯グラフがその場で更新。
   - カット／テロップ／SE: それぞれ表で追加・編集・削除。「カット＋」ボタンで秒数入力だけで素早く追加。
   - 自由メモ: 見出しつきで複数。
   - 「型として保存」ボタン
3. **型**: 型の一覧。「この型で企画を作る」で構成をコピーした企画を新規作成。型ごとに、その型から作った投稿の件数と平均再生数を表示。
4. **分析**: 再生数の多い順に構成帯グラフを並べて比較。表で「フック秒数／オチ位置（尺の％）／CTAの有無／カット数／平均カット秒数」と再生数・高評価・コメントを並べる。種別で絞り込み。

## エラー・例外
- 画面共有が拒否・中断された: ボタンを「共有をやり直す」に切り替えて案内を出す。
- 小窓がポップアップブロックされた: 許可の案内を表示し、リンクとしても開けるようにする。
- 保存容量: スクショは JPEG（品質0.85、長辺1080px上限）に縮小して保存。
- 読み込みJSONが壊れている: 何も上書きせずエラー表示。読み込みは「追加」か「置き換え」を選ぶ。
- 削除は確認つき。

## 動作確認
- ヘッドレスブラウザで: 新規作成→ブロック・カット・テロップ・SE・メモ追加→再読み込み後も残る、型保存→型から企画作成、分析表の数値、JSON書き出し→読み込みで同じになる。
- スクショはテスト用の画面共有ストリームで撮影→保存されることを確認。

## 範囲外
- 動画の自動解析（カット自動検出・文字起こし）
- 再生数の自動取得
- スマホ対応（表示は崩れない程度）
